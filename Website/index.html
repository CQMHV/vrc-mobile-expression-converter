Install with your package manager

Open VCC or ALCOM, add this repository, and install Mobile Expression Converter in an Avatar project. Make sure the official VRChat and NDMF repository are available.

https://cqmhv.github.io/vrc-mobile-expression-converter/index.json

Build as usual

Add the component to your avatar root. Select the face renderer, switch to Android, and build. NDMF converts supported lilToon / Poiyomi materials and material-switching animations in the build copy.

VRCQuestTools is optional and can adapt the rest of your avatar. Windows builds skip conversion.

Approximate conversion: Multiply preserves dark overlays and alpha masks. White tears and highlights may become faint or disappear. iOS device behavior has not been tested.
